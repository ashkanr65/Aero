# Automatic browser import — October 20, 2026

The portable app remains version **1.0.3**. In Settings > Import browser data, choose Edge, Chrome, Firefox, or Opera. Aero detects standard installed profiles, including Chromium release channels, Firefox profiles.ini entries, and Opera root/nested profiles. A single detected profile is read automatically; multiple profiles get a display-name picker. A custom-folder option remains available for installations outside the standard locations.

The original Edge failure was reproduced: its Bookmarks file was valid, but SQLite reported `database is locked` for History. The old importer discarded all results and replaced the cause with a generic error. The new importer takes a read-only SQLite online backup into memory when possible. For exclusive locks, it retries checked copies of the database and its WAL/rollback journal in a temporary directory, verifies stable source bytes and file state, validates and recovers only the copy, and reads the result into memory. Temporary snapshots are removed on normal completion/error. A crash or forced termination can leave a temporary `aero-import-*` directory. A stable copy of an actively written database is best effort, not a transactional guarantee; close the source browser and retry if data is changing or an integrity check fails. Source databases are never modified by the importer.

Bookmark and history failures are independent. Available data stays importable, and the UI shows the specific failure for the unavailable category. Nothing is added to Aero until **Import selected data** is pressed. Checkboxes control persistence, duplicates are removed, and existing Aero entries are preserved. Import completion is shown after saving, rather than after merely reading a profile. Read/import limits are 100,000 supported bookmarks/history pages and 512 MB per SQLite snapshot file; limits are reported. Aero's local storage quota can reject a very large import; that error is shown without overwriting existing data. Bookmark folder hierarchy is flattened into Aero's favorites list. History retains the most recent recorded visit per URL rather than every individual visit. Only HTTP/HTTPS pages are accepted. Open tabs, cookies, signed-in sessions, extensions, and browser sync are not imported.

## Password transfer

The wizard can launch the selected source browser's password settings and explains how to export and finish through Aero Password Manager's existing CSV import and Windows authentication. It does not open Login Data/logins.json credential stores, decrypt browser keys, or retrieve saved passwords, and does not bypass browser encryption or automate authentication prompts. Chromium Local State is parsed only for profile display names and the last-used profile; encryption metadata is not used or returned. The user must confirm the source browser's export and choose the resulting file in Aero. Check the source browser's active profile before exporting. A CSV export contains readable passwords and should be deleted after successful import.

References: [Microsoft Edge password export](https://support.microsoft.com/en-us/edge/export-passwords-in-microsoft-edge), [Firefox import limitations](https://support.mozilla.org/en-US/kb/import-data-another-browser), [SQLite online backup](https://www.sqlite.org/backup.html).
